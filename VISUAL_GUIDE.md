## 组件层级结构

```
ContentView (主视图)
    └── ZStack
        ├── ARViewContainer (AR相机层)
        │
        ├── if isBubbleVisible
        │   └── GeometryReader ← 获取屏幕尺寸
        │       └── VStack
        │           ├── HStack
        │           │   └── ReactTextBar ← 我们的组件
        │           │       ├── .frame(width: 90% 屏幕宽度)
        │           │       └── .frame(height: 80pt)
        │           │
        │           └── Spacer()
        │
        └── TestButton (测试按钮层)

ReactTextBar 内部结构:
    └── GeometryReader
        └── ZStack(alignment: .topTrailing)
            ├── Text (气泡内容)
            │   ├── .font(.system(size: 16))
            │   ├── .foregroundColor(textColor)
            │   ├── .padding(.horizontal, 16)
            │   ├── .padding(.vertical, 12)
            │   └── .background(BubbleWithLCutout)
            │
            └── CircleComponent (圆形)
                ├── Circle (填充层)
                │   ├── .fill(blue.opacity(0.3))
                │   └── .frame(40×40)
                │
                └── Circle.overlay (边框层)
                    └── .stroke(blue, width: 2)
```

## 尺寸规格表

| 元素 | 尺寸 | 说明 |
|------|------|------|
| **气泡高度** | 80pt | 固定高度 |
| **气泡宽度** | 屏幕宽度 × 90% | 动态宽度 (约3倍原宽度) |
| **文字大小** | 16pt | System字体 |
| **水平内边距** | 16pt | 左右padding |
| **垂直内边距** | 12pt | 上下padding |
| **圆形直径** | 40pt | 固定尺寸 |
| **缺口尺寸** | 44pt × 44pt | 圆形 + 4pt空隙 |
| **空隙** | 4pt | 缺口与圆形的间距 |
| **圆角半径** | 18pt | 气泡框圆角 |
| **圆形边框** | 2pt | 蓝色描边 |

## 响应式设计

### iPhone SE (小屏幕 - 375pt 宽)
```
气泡宽度: 375 × 0.9 = 337.5pt
可用文本宽度: 337.5 - 44(缺口) - 32(padding) = 261.5pt
```

### iPhone 15 Pro (中等 - 393pt 宽)
```
气泡宽度: 393 × 0.9 = 353.7pt
可用文本宽度: 353.7 - 44 - 32 = 277.7pt
```

### iPhone 15 Pro Max (大屏幕 - 430pt 宽)
```
气泡宽度: 430 × 0.9 = 387pt
可用文本宽度: 387 - 44 - 32 = 311pt
```

## 动画效果

### 出现动画
```
初始状态 (t=0ms):
   opacity: 0
   scale: 0.8
   offset: y = -20

过渡中 (t=150ms):
   opacity: 0.5
   scale: 0.9
   offset: y = -10

最终状态 (t=300ms):
   opacity: 1.0
   scale: 1.0
   offset: y = 0

动画类型: spring(response: 0.3, dampingFraction: 0.7)
```

### 消失动画
```
最终状态 → 初始状态 (反向播放)
持续时间: 300ms
```

## 代码片段速查

### 基本使用
```swift
ReactTextBar(text: "Your message")
    .frame(width: 350)
```

### 自定义颜色
```swift
ReactTextBar(
    text: "Custom",
    backgroundColor: .blue.opacity(0.2),
    textColor: .white
)
```

### 响应式宽度
```swift
GeometryReader { geometry in
    ReactTextBar(text: "Message")
        .frame(width: geometry.size.width * 0.9)
}
```
